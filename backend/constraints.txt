# 백엔드 런타임 의존성의 정확한 버전(pip constraints). Dockerfile이 `pip install -c constraints.txt .`로 쓴다.
# pyproject.toml의 하한(보안 패치 하한 포함)은 그대로 두고, 이 파일은 빌드할 때마다 같은 버전이 깔리게만 한다.
# 버전을 바꾸는 것은 업그레이드 결정이다. 바꿀 때만(의도적으로):
#   1) grep '^#' backend/constraints.txt > /tmp/c && mv /tmp/c backend/constraints.txt   # 주석만 남기면 고정 해제
#   2) docker build --no-cache -t weave-backend:deps backend
#   3) docker run --rm --entrypoint pip weave-backend:deps freeze --exclude weave-backend | LC_ALL=C sort >> backend/constraints.txt
#   4) git diff backend/constraints.txt 로 바뀐 버전을 검토하고 승인받는다
#   5) docker compose build --no-cache backend && docker compose up -d backend && make test-backend
#      && scripts/prod-smoke.sh weave-backend  — 같은 이미지 ID로 둘 다 통과해야 한다
#   6) 목록 해시(grep -v '^#' backend/constraints.txt | LC_ALL=C sort | shasum -a 256)·이미지 ID·결과를 커밋 본문에 남긴다
